# Sistem Manajemen Ekspedisi Paket

Program ini merupakan aplikasi berbasis Java yang digunakan untuk mengelola data pengiriman paket menggunakan konsep Object Oriented Programming (OOP).

## Fitur Program
- Menambahkan dan menampilkan data paket.
- Mengelola data pengirim.
- Membuat transaksi pengiriman.
- Menghitung biaya pengiriman berdasarkan berat paket.
- Mencari paket berdasarkan kode.
- Mengelola antrean paket menggunakan Queue.
- Menampilkan laporan pengiriman.

## Teknologi
- Bahasa pemrograman Java
- IntelliJ IDEA
- Struktur data Queue

## Struktur Class
1. Main
2. Paket
3. Pengirim
4. Pengiriman
5. KantorEkspedisi
6. Queue
